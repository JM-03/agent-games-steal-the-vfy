zkVerify Agent Games — Wildcard

Every move provably bound to a pre-committed strategy

An agent that can only do what it committed to before acting — proven in zero knowledge. Before a match, the owner picks 8 strategy numbers and a random salt and publishes only a Poseidon commitment; the strategy stays secret. Each turn, the agent decides strictly by the official circuit's decision list, generates a Groth16 proof against the official vfy-policy circuit, self-verifies it locally, and only then answers. A wrong move cannot be proven at all — the circuit refuses, and the agent fails closed to HOLD.

The game below is the demo. The product is the treasury guard: the same commit → prove → execute pattern with real money at stake — no spend executes without a Groth16 proof, and a spend over the cap has no proof at all.

The treasury guard

An agent holding the keys to a 100 VFY treasury. Before the keys change hands, the owner commits a policy — spend capped at 5 VFY per move, a reserve floor of 50 (fortify instead of spending below it), a counterparty floor of 20 (hold below it) — under commitment 0x1b63…a2a24 (strategy [5,50,20,0,0,0,0,0]). The agent can only spend what the policy allows, and every spend needs a Groth16 proof against the official circuit. The loop, end to end

Commit → move → prove → Kurier → result

01CommitOwner publishes a Poseidon commitment over the strategy + salt. The strategy itself is never published.
02MoveEach turn, the agent decides strictly by the circuit's decision list: FORTIFY → HOLD → EXTRACT.
03ProveA Groth16 proof is generated against the official vfy-policy circuit and self-verified locally. A move outside the policy has no proof at all.
04KurierProofs are submitted to Kurier for verification on zkVerify mainnet (see status below).
05ResultOnly a proven move is answered; anything else fails closed to HOLD.

Reveal — commit → act → reveal

Only the DEMO commitment is ever revealed. The main commitment (0x0b9f…1cb39) and its salt stay secret — there is no ceremony in which the main salt is revealed. A commitment nobody can ever check is a claim; a commitment that is revealed and recomputed is evidence.

How to read this page

This page is a transcript of real local runs of the repo's demo scripts, recorded 15–17 Nov 2026 (main + defensive matches on 15 Nov; refusal, treasury and reveal transcripts on 16 Nov; the Finalized Kurier job on 17 Nov). What is real: the turn handler (src/turn.ts), the Groth16 proofs (snarkjs + official vfy-policy circuit), and the local self-verification of every proof. What is simulated: the opponent (a fixed script) and the balance resolver (documented rules in the repo — FORTIFY costs 2 VFY and blocks up to 6 on the next turn; EXTRACT steals up to the requested amount; both sides' gains are computed from start-of-turn balances and applied together). The treasury examples are precomputed transcripts of npm run demo:treasury — the verdicts are what the script printed, labelled as such. The match is a local simulation, not a tournament game — the Steal tournament ran 13–17 Nov 2026, so this demo + proofs are the Wildcard entry. The match simulator above uses the same decision list and resolver as the repo's demo — it just runs them in your browser instead of in Node.

Proof timings vary run to run; the moves, balances and final scores are deterministic. Reproduce it yourself: npm install && npm run build && npm run demo (see the repo README).
