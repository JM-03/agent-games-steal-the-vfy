# Proof for demo match turn 1 — verify it yourself

A real Groth16 proof from the official `vfy-policy` circuit, generated by
`npm run export:proof` for turn 1 of the demo match (matchId `12345678-1234-1234-1234-123456789abc`,
turn 1, balances 100/100, action EXTRACT 10, commitment `0x0b9f4672eb0b10bba098b648216126cb6256f43b0879833483b7f4631f61cb39`).

## Verify (no repo code runs — only snarkjs)

```bash
npm run verify:proof
```

Expected output: `[INFO]  snarkJS: OK!` — the proof verifies against the
official verification key (`verification_key.json`, exported from
`circuits/vfy-policy_final.zkey`).

## What this proves — and what it does not

- It proves the turn-1 move (EXTRACT 10) was permitted by the committed
  strategy. Public signals: `[digest, commitment, matchId, turnNumber,
  selfBalance, opponentBalance, action, amount, circuitVersion]`.
- It does NOT prove the strategy is wise, and it does NOT prove on-chain
  finalization — that needs a Kurier job id (see Proof Reference in the
  README; the first Steal job id is still pending).
- Our server alone can never produce VERIFIED — only Kurier / zkVerify
  mainnet can. This file is the raw material a second, independent
  verifier checks.
